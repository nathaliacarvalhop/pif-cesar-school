# Lista-Cap2

Lista de exercícios do Capítulo 2 de PIF.

- `respostas.md`: questões teóricas e analíticas (1 a 6).
- `exercicio07.c` até `exercicio28.c`: questões práticas.
- `exercicio03.c`: código solicitado na questão 03, que é uma questão prática dentro da Parte I.

## Compilação

Exemplo:

```bash
gcc exercicio14.c -o exercicio14 -lm
```

Para os outros programas sem funções de `<math.h>`:

```bash
gcc exercicio07.c -o exercicio07
```
