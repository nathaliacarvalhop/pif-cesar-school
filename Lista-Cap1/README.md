# PIF – Lista de Exercícios – Capítulo 1

Estrutura preparada conforme as orientações da lista:

- `respostas.md`: respostas das questões teóricas e explicações.
- `exercicioXX.c`: um arquivo `.c` individual para cada questão prática.
- As questões 21 possui três versões independentes, conforme solicitado.

## Compilação

Com GCC/MinGW:

```bash
gcc exercicio01.c -o exercicio01.exe
./exercicio01.exe
```

No Windows, também pode executar o `.exe` pelo terminal.

> Observação: os exercícios que usam `system("PAUSE")` foram mantidos próximos ao material do enunciado e são voltados ao ambiente Windows/MinGW.
